# MproWave for Android

Make music on your phone: sketch tracks, write lyrics with AI, and share with other producers.

## Download

Visit **https://mprowave.netlify.app** (or scan its QR code with your phone), or get the APK from **[Releases](https://github.com/AZAKIDS/mprowave-app/releases/latest)**.

## Install

1. Download `MproWave-<version>.apk` on your Android phone (Android 7.0 or newer).
2. Open it. If Android asks, allow your browser or file manager to install unknown apps.
3. If Google Play Protect warns that the app is unrecognised, choose **More details → Install anyway**. MproWave isn't on the Play Store yet, so Play Protect hasn't seen it before.

This repository only hosts the release builds.
